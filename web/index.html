    Obsidian vaults

    Connect an Obsidian vault so Myra can show and read your notes. She only reads, never changes anything, and only where you allow it.

    1. Connect a vault below.
    2. Give access. Each project or board chooses which folders it may read. Use Give access… on the vault, or right-click a project or board and choose Vault access.
    3. Allow AI reading (optional). In the same dialog, switch on “Let Myra read these with AI”. Then add the vault under Myra sees in Myra’s chat for the messages where you want her to look. Only then are matching notes sent to Claude, a cloud service.

    Folders you mark off-limits, and any note tagged #private, are never read.
